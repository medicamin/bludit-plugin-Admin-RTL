# Bludit Plugin: Admin-RTL
![alt text](https://github.com/medicamin/bludit-plugin-Admin-RTL/blob/main/screenshot.png?raw=true)

Change the [bludit](http://bludit.com/) 3.22 admin dashboard to RTL direction for Right to Left languages such as Persian or Arabic 

 - No settings, just activate the plugin. 
 - Adds [Vazirmatn](https://github.com/rastikerdar/vazirmatn) font-family to the admin area. 
 - You can change the font in the *fonts* folder and the font-family in *rtl.css* 
 - You can add or change any css attribute to the *rtl.css* file
 - English characters in the input fields such as plugin settings, remains LTR
